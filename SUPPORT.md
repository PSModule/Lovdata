# Support

Where to ask depends on what the question is about.

## This module

Use [GitHub Issues](https://github.com/PSModule/Lovdata/issues) on this repository for bugs, feature requests, and questions
about the `Lovdata` module. Follow the [issue format](https://msxorg.github.io/docs/Ways-of-Working/Issue-Format/) so the
report is actionable without follow-up questions.

For anything that does not fit in an issue, email [psmodule@psmodule.io](mailto:psmodule@psmodule.io) or join the
[PSModule Discord](https://discord.psmodule.io).

Security problems are handled separately — see [SECURITY.md](SECURITY.md).

## The Lovdata API and its data

Questions about API keys, endpoint behaviour, rate limits, or the legal content itself are answered by Lovdata, not by this
module's maintainers:

- Lovdata API tech support: [api@lovdata.no](mailto:api@lovdata.no)
- [Lovdata API documentation](https://api.lovdata.no/swagger/index.html)
- [Lovdata's open data information](https://lovdata.no/info/api)

## The PowerShell Gallery

Problems with the package listing itself, rather than the module code:

- [PowerShell/PowerShellGallery issues](https://github.com/PowerShell/PowerShellGallery/issues)
- [cgadmin@microsoft.com](mailto:cgadmin@microsoft.com)
